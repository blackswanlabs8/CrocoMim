# Реализация маркетплейса словарей

## Обзор

Добавлена функциональность маркетплейса словарей, хранилища пользовательских словарей и генерации словарей с лимитами.

## Основные компоненты

### 1. Маркетплейс словарей (Marketplace)

**Backend API:**
- `GET /marketplace/dictionaries` - Получить список публичных словарей
  - Параметры: `difficulty`, `topic`, `limit`, `offset`
- `GET /marketplace/dictionaries/<id>` - Получить информацию о словаре (превью)
- `POST /marketplace/dictionaries/<id>/add` - Добавить словарь в библиотеку пользователя

**Характеристики:**
- Публичные словари имеют `visibility: "public"` и `status: "published"`
- Фильтрация по сложности и теме
- Пагинация результатов

### 2. Хранилище словарей пользователя

**Backend API:**
- `GET /user/dictionaries` - Список словарей пользователя
- `POST /user/dictionaries` - Создать новый словарь
- `GET /user/dictionaries/<id>` - Получить словарь с содержимым
- `PUT /user/dictionaries/<id>` - Обновить словарь
- `DELETE /user/dictionaries/<id>` - Удалить словарь

**Типы видимости:**
- `private` - виден только владельцу
- `unlisted` - виден по прямой ссылке
- `public` - выставлен на маркетплейс

### 3. Генерация словарей

**Backend API:**
- `POST /generate-dictionary` - Сгенерировать словарь через ИИ
- `GET /user/generation-info` - Получить информацию о доступных генерациях
- `GET /dict/status` - Проверить статус лимита

**Лимиты:**
- 10 бесплатных генераций на пользователя
- После исчерпания - ожидание 24 часа между генерациями
- Счётчик генераций хранится в профиле пользователя

### 4. Логика работы

```
Пользователь → Генерация словаря (ИИ) → Редактирование → Сохранение
                                                      ↓
                                    Выбор видимости: private/public
                                                      ↓
                                    Если public → попадает на маркетплейс
```

## Изменения в базе данных

### Таблица `dictionaries`
- `visibility` - уровень доступа (private/unlisted/public)
- `status` - статус модерации (draft/published/moderation/rejected/blocked)
- `source` - источник создания (manual/ai/imported)

### Новые функции в `dictionary_store.py`:
- `list_public_dictionaries()` - список для маркетплейса
- `get_public_dictionary()` - превью словаря
- `add_dictionary_to_user()` - добавление в библиотеку

### Новые функции в `user_auth.py`:
- `get_user_generation_info()` - информация о лимитах генерации
- Обновлён `update_last_generation()` - теперь увеличивает счётчик

## Рекомендации по UX

1. **Генерация словаря:**
   - Показывать счётчик доступных генераций в интерфейсе
   - Предупреждать перед использованием последней генерации
   - Показывать таймер до следующей генерации если лимит исчерпан

2. **Редактирование:**
   - Inline-редактирование слов после генерации
   - Возможность добавить/удалить слова
   - Предпросмотр перед сохранением

3. **Публикация:**
   - Чёткий toggle "Приватный/Публичный"
   - Предупреждение что публичный словарь попадёт на маркетплейс
   - Возможность изменить видимость позже

4. **Маркетплейс:**
   - Поиск и фильтры (сложность, тема)
   - Превью словаря (название, тема, кол-во слов, сложность)
   - Кнопка "Добавить в мою библиотеку"
   - Рейтинг/отзывы (опционально)
