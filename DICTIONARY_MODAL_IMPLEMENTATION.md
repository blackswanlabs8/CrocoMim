# Реализация интерфейса словарей в CrocoMim

## Обзор изменений

Функционал управления словарями (маркетплейс, хранилище пользователя, генератор) реализован как **модальное окно** в основном приложении, а не как отдельная страница. Это соответствует архитектуре остальных функций CrocoMim.

## Изменения в файлах

### 1. `/workspace/public/index.html`
**Изменение:** Кнопка "Словари" в шапке изменена с ссылки (`<a href="/dictionaries">`) на обычную кнопку (`<div class="icon-btn">`).

**До:**
```html
<a href="/dictionaries" class="icon-btn" id="btnDictionaries" ...>
```

**После:**
```html
<div class="icon-btn" id="btnDictionaries" ...>
```

### 2. `/workspace/public/scripts/app.js`
**Изменение:** Добавлен обработчик клика на кнопку "Словари", который открывает модальное окно.

**Код:**
```javascript
// Dictionaries button - show modal with dictionary management interface
const btnDictionaries = document.getElementById('btnDictionaries');
if (btnDictionaries) {
  btnDictionaries.addEventListener('click', (e) => {
    e.preventDefault();
    showDictionaryModal();
  });
}
```

### 3. `/workspace/public/scripts/dictionaries.js`
**Изменения:**

#### a) Экспорт функции `showDictionaryModal`
Добавлена новая функция, которая создаёт и отображает модальное окно с управлением словарями:

- Создаёт динамически HTML модального окна
- Включает три вкладки: "Мои словари", "Маркетплейс", "Конструктор"
- Инициализирует обработчики событий для переключения вкладок
- Загружает данные при открытии каждой вкладки

#### b) Экспорт функции `loadMyDictionaries`
Функция загружает словари пользователя из API и отображает их в сетке карточек.

**Подпись:**
```javascript
window.loadMyDictionaries = async function() { ... }
```

#### c) Обновление `renderMyDictionaries`
Функция теперь принимает параметры элементов DOM для гибкости использования в модалке:

```javascript
function renderMyDictionaries(dictionaries, gridEl = elements.myDictionariesGrid, emptyEl = elements.myDictionariesEmpty) { ... }
```

## Архитектура модального окна

### Структура
```
┌─────────────────────────────────────────┐
│  📚 Мои Словари                    [✕] │
├─────────────────────────────────────────┤
│ [Мои словари] [Маркетплейс] [Конструк.]│
├─────────────────────────────────────────┤
│                                         │
│  Содержимое активной вкладки            │
│                                         │
└─────────────────────────────────────────┘
```

### Вкладки

#### 1. Мои словари
- Поиск по названию
- Фильтр по категории
- Фильтр по приватности (приватные/публичные)
- Сетка карточек словарей
- Пустое состояние с кнопкой создания

#### 2. Маркетплейс
- Поиск по названию
- Фильтр по категории
- Фильтр по языковой паре
- Сетка карточек публичных словарей
- Кнопка "Добавить в библиотеку" в превью

#### 3. Конструктор
- Индикатор доступных генераций
- Пошаговый мастер (3 шага):
  1. Основные настройки (тема, языки, сложность, кол-во слов)
  2. Редактирование сгенерированных слов
  3. Сохранение (название, описание, видимость)

### Модальные окна внутри модалки
- **Preview Modal** - превью словаря из маркетплейса
- **Word Edit Modal** - редактирование отдельного слова
- **Toast Container** - уведомления об операциях

## Backend API (уже реализован)

| Endpoint | Method | Описание |
|----------|--------|----------|
| `/user/dictionaries` | GET | Список словарей пользователя |
| `/user/dictionaries` | POST | Создать словарь |
| `/user/dictionaries/<id>` | PUT | Обновить словарь |
| `/user/dictionaries/<id>` | DELETE | Удалить словарь |
| `/marketplace/dictionaries` | GET | Список публичных словарей |
| `/marketplace/dictionaries/<id>` | GET | Превью словаря |
| `/marketplace/dictionaries/<id>/add` | POST | Добавить в библиотеку |
| `/generate-dictionary` | POST | Генерация через ИИ |
| `/user/generation-info` | GET | Информация о лимитах |

## Лимиты генераций

- **10 бесплатных генераций** на пользователя
- После исчерпания - **24 часа ожидания** между генерациями
- Счётчик отображается в шапке конструктора

## UX-принципы

1. **Прогрессивное раскрытие** - сложные операции (редактирование, сохранение) вынесены в отдельные шаги/модалки
2. **Визуальная обратная связь** - toast-уведомления, спиннеры загрузки, пустые состояния
3. **Минимализм** - только необходимые элементы управления, действия при наведении
4. **Консистентность** - единый стиль с остальным приложением (CSS-переменные, классы)
5. **Доступность** - ARIA-атрибуты, управление с клавиатуры

## Стилизация

Все стили используют существующие CSS-переменные CrocoMim:
- `--bg-card` - фон карточек
- `--border` - цвет границ
- `--text` / `--text-secondary` - цвета текста
- `--primary` - акцентный цвет
- `--bg-input` - фон полей ввода

Адаптивность обеспечивается через:
- Grid-layout с `minmax(280px, 1fr)`
- Flexbox с `flex-wrap: wrap`
- Максимальная высота модалки с прокруткой


## Развёртывание

1. Убедитесь, что backend запущен и доступен
2. Откройте главную страницу CrocoMim
3. Нажмите на кнопку 📚 в шапке (справа от логотипа)
4. Модальное окно откроется с вкладкой "Мои словари"
