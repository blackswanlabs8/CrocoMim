# Backend API

Этот документ описывает минимальный Flask-бэкенд приложения CrocoMim: доступные маршруты, формат запросов и вспомогательные функции.

## Запуск
Бэкенд запускается из `backend/app.py`. По умолчанию сервер слушает `http://localhost:3000`. Путь для сохранения отзывов задаётся переменными окружения `DATA_DIR` (каталог) и `FEEDBACK_FILE` (имя файла). При отсутствии каталога он будет создан автоматически.

## Маршруты
### `GET /`
- **Описание:** проверка живости сервера.
- **Параметры:** нет.
- **Ответ:** `{ "message": "Flask backend is alive" }`.

### `GET /healthz`
- **Описание:** health-check.
- **Параметры:** нет.
- **Ответ:** `{ "ok": true }`.

### `POST /api/feedback`
- **Описание:** принимает отзыв от клиента и сохраняет его построчно в лог-файл.
- **Тип:** `POST`
- **Заголовки:** `Content-Type: application/json`
- **Тело запроса (JSON):**
  - `category` — **обязательный**, одно из `typo`, `difficulty`, `other`.
  - `message` — **обязательный**, строка длиной не менее 10 символов.
  - `email` — опционально, непустая строка.
  - `consent` — **обязательный**, булев `true`.
  - `context` — опционально, объект с произвольными данными (например, режим игры, слово, сложность).
  - `client` — опционально, объект с данными клиента (например, userAgent, platform).
- **Ответы:**
  - `200 { "ok": true }` — отзыв сохранён.
  - `400 { "ok": false, "error" | "errors": [...] }` — некорректное тело или ошибки валидации.
  - `500 { "ok": false, "error": "Failed to persist feedback: ..." }` — не удалось записать данные на диск.

## Вспомогательные функции
### `backend/app.py`
- `_resolve_storage_path()` — возвращает путь к файлу для сохранения отзывов с учётом `DATA_DIR` и `FEEDBACK_FILE`, создаёт каталог при необходимости.
- `_validate_feedback(payload)` — проверяет входные данные, возвращает объект с полем `ok` и списком ошибок (если есть).
