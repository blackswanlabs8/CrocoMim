# Упаковка CrocoMim в офлайн-APK для Android

Ниже описан рекомендуемый процесс, который позволяет превратить текущую сборку CrocoMim в автономное Android-приложение. Схема основана на [Capacitor](https://capacitorjs.com/) и предполагает, что статические файлы из каталога `public/` будут встроены в APK и доступны без подключения к интернету.

> ⚡ **Почему Capacitor?**
>
> - быстрый старт без переписывания фронтенда;
> - полноценный офлайн: `index.html`, стили, скрипты и ассеты попадают в APK;
> - возможность подключать плагины для доступа к нативным API при необходимости.

## 0. Подготовьте сборку сайта

1. Убедитесь, что все ресурсы в `public/index.html` подключаются относительными путями (`./styles/main.css`, `./scripts/app.js` и т. д.).
2. Если вы используете систему сборки (Vite, React, Vue), соберите проект командой `npm run build` и положите итоговые файлы в каталог `dist/`. Для текущего репозитория можно использовать содержимое `public/` как готовую сборку.

## 1. Установите и инициализируйте Capacitor

```bash
npm install --save @capacitor/core
npm install --save-dev @capacitor/cli
npx cap init
# App name: CrocoApp (пример)
# App ID: com.yourdomain.croco (пример)
```

В каталоге появится файл конфигурации `capacitor.config.(ts|json)`.

## 2. Настройте `capacitor.config.ts`

```ts
import { CapacitorConfig } from '@capacitor/cli';

const config: CapacitorConfig = {
  appId: 'com.yourdomain.croco',
  appName: 'CrocoApp',
  webDir: 'public',
  server: {
    androidScheme: 'https'
  }
};

export default config;
```

- `webDir` указывает на каталог со статическими файлами.
- `androidScheme: 'https'` гарантирует корректную загрузку локальных ресурсов внутри WebView.

## 3. Добавьте платформу Android и синхронизируйте ассеты

```bash
npx cap add android
npx cap copy
npx cap sync
```

Эти команды скопируют файлы из `public/` в `android/app/src/main/assets/public`.

## 4. Откройте проект в Android Studio

```bash
npx cap open android
```

После открытия вы получите полноценный Android-проект, который можно настраивать и собирать стандартными средствами.

## 5. Сборка релизного APK

1. В Android Studio выберите **Build → Generate Signed Bundle / APK…**.
2. Создайте (или выберите существующий) keystore и укажите релизную конфигурацию.
3. Соберите `app-release.apk`. При необходимости подпишите и выполните `zipalign` с помощью стандартных инструментов Android SDK.
4. Установите APK на устройство (не забудьте разрешить установку из неизвестных источников).

## 6. Обновление контента без релиза

Если нужно обновлять кэшированные файлы «по воздуху», добавьте в проект Service Worker или собственную систему обновлений. Приложение уже содержит `public/service-worker.js`, поэтому при необходимости можно расширить его логику.

---

При желании можно подключить дополнительные плагины Capacitor (камера, хранение данных, уведомления и т. д.) — это позволит постепенно добавлять нативные возможности без полного переписывания фронтенда.
