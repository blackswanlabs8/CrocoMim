# Руководство по интерфейсу словарей CrocoMim

## Обзор

Реализован полный интерфейс для системы управления словарями, включающий:
- **Маркетплейс** — каталог публичных словарей от сообщества
- **Хранилище пользователя** — личные словари с управлением приватностью
- **Конструктор** — мастер генерации и редактирования словарей с помощью ИИ

## Структура файлов

```
public/
├── dictionaries/
│   └── index.html          # Главная страница словарей
├── styles/
│   └── dictionaries.css    # Стили страницы словарей
├── scripts/
│   └── dictionaries.js     # Логика frontend
└── index.html              # Обновлённое главное меню (добавлена кнопка)
```

## Навигация

### Доступ к странице словарей
- Кнопка **📚 Мои Словари** в шапке главного меню
- URL: `/dictionaries/index.html`
- Кнопка "Назад" возвращает на главную страницу

### Элементы навигации в шапке
```
[← Назад] [📚 Мои Словари] [✨ 10] [👤 Профиль]
                         ↑
                   Счётчик генераций
```

## Вкладки интерфейса

### 1. Мои словари

**Назначение:** Управление личными словарями пользователя

**Функции:**
- Просмотр всех словарей пользователя
- Фильтрация по названию, категории, приватности
- Быстрые действия: редактировать, удалить
- Переход к созданию нового словаря

**Элементы карточки словаря:**
```
┌─────────────────────────────────┐
│ Название           🔒 Приватный │
│ 🌐 ru → en  📝 20 слов  📂 Наука│
│ Краткое описание...             │
│ [✏️ Редактировать] [🗑 Удалить] │
└─────────────────────────────────┘
```

**Пустое состояние:**
- Сообщение "У вас пока нет словарей"
- Кнопка "Перейти в маркетплейс"

---

### 2. Маркетплейс

**Назначение:** Поиск и добавление публичных словарей

**Функции:**
- Каталог всех публичных словарей
- Поиск по названию и описанию
- Сортировка: популярные, новые, по рейтингу
- Фильтры по категории и языку
- Предпросмотр перед добавлением
- Добавление в личную библиотеку

**Элементы карточки:**
```
┌─────────────────────────────────┐
│ Название           🌍 Публичный │
│ 🌐 ru → en  📝 20 слов  📂 Наука│
│ Краткое описание...             │
│ [👁 Предпросмотр] [➕ Добавить] │
└─────────────────────────────────┘
```

**Модальное окно предпросмотра:**
- Полная информация о словаре
- Список всех слов (прокручиваемый)
- Кнопка "Добавить в библиотеку"

---

### 3. Конструктор

**Назначение:** Пошаговое создание словаря с помощью ИИ

#### Шаг 1: Основные настройки

**Поля ввода:**
- **Тема словаря** * (обязательно) — текстовое описание
- **Исходный язык** — выбор из списка (ru, en, es, de, fr)
- **Целевой язык** — выбор из списка
- **Уровень сложности** — лёгкий/средний/сложный
- **Количество слов** — число от 5 до 100
- **Категория** — выбор из предопределённых

**Кнопка:** "Сгенерировать превью"

#### Шаг 2: Редактирование словаря

**Информационные чипы:**
- Языковая пара (например: Русский → English)
- Уровень сложности
- Количество слов

**Таблица редактора:**
| Слово (исходный) | Перевод/Описание | Подсказка | ✕ |
|-----------------|-----------------|-----------|---|
| input field     | input field     | input field| 🗑|

**Инструменты:**
- ➕ Добавить слово
- 📤 Импортировать (массовый ввод)
- 📥 Экспортировать

**Кнопки действий:**
- 🔄 Перегенерировать
- 💾 Сохранить словарь

#### Шаг 3: Настройки публикации

**Поля:**
- **Название словаря** * (обязательно)
- **Описание** (необязательно)

**Выбор приватности:**
```
┌──────────────────┐  ┌──────────────────┐
│ 🔒 Приватный     │  │ 🌍 Публичный     │
│ Видите только вы │  │ Будет доступен   │
│                  │  │ в маркетплейсе   │
└──────────────────┘  └──────────────────┘
```

**Информация о стоимости:**
- Стоимость генерации: 1 попытка
- Осталось генераций: N

**Кнопки:**
- Назад к редактированию
- ✅ Сохранить и опубликовать

## Модальные окна

### 1. Предпросмотр словаря (Marketplace)
- Заголовок с названием
- Мета-информация (языки, сложность, категория)
- Список слов с прокруткой
- Кнопки: Отмена / Добавить в библиотеку

### 2. Добавить/Редактировать слово
- Поля: слово, перевод, подсказка
- Кнопки: Отмена / Сохранить

### 3. Импорт слов
- Текстовое поле для массового ввода
- Формат: `слово, перевод, подсказка` (каждая пара с новой строки)
- Кнопки: Отмена / Импортировать

## Уведомления (Toast)

**Типы уведомлений:**
- ✅ **success** — зелёная полоса слева
- ❌ **error** — красная полоса слева  
- ℹ️ **info** — синяя полоса слева

**Позиция:** правый нижний угол экрана

**Автозакрытие:** через 3 секунды

**Примеры сообщений:**
- "Словарь сгенерирован! Отредактируйте и сохраните."
- "Словарь сохранён!"
- "Превышен лимит генераций. Попробуйте через 24 часа."
- "Словарь добавлен в библиотеку!"

## Адаптивный дизайн

### Мобильная версия (< 768px)
- Вкладки с уменьшенными отступами
- Фильтры в вертикальную колонку
- Карточки словарей в одну колонку
- Кнопки действий всегда видны (не при наведении)
- Шаги мастера в полную ширину

### Планшет (768px - 1024px)
- Сетка карточек: 2 колонки
- Горизонтальные фильтры

### Десктоп (> 1024px)
- Сетка карточек: автозаполнение (min 280px)
- Максимальная ширина контента: 1200px

## Индикатор генераций

**Расположение:** шапка страницы, справа

**Внешний вид:**
```
✨ 10
```

**Логика отображения:**
- Зелёный фон с прозрачностью 10%
- Иконка волшебства (✨)
- Число доступных генераций
- Обновляется автоматически после каждой генерации

**Предупреждения:**
- При 0 генераций: блокировка кнопки генерации
- Сообщение: "Превышен лимит генераций. Попробуйте через 24 часа."

## UX-принципы

### 1. Прогрессивное раскрытие
- Действия на карточках видны только при наведении (десктоп)
- Модальные окна для сложных операций
- Мастер разбит на логические шаги

### 2. Обратная связь
- Toast-уведомления для всех действий
- Индикаторы загрузки (спиннеры)
- Пустые состояния с подсказками

### 3. Предотвращение ошибок
- Валидация обязательных полей
- Подтверждение удаления
- Блокировка при исчерпании лимита

### 4. Эффективность
- Горячие клавиши (в разработке)
- Массовый импорт/экспорт
- Быстрая фильтрация

### 5. Доступность
- ARIA-атрибуты для скринридеров
- Контрастность цветов
- Фокус-индикаторы
- Управление с клавиатуры

## Интеграция с API

### Endpoints (frontend → backend)

| Действие | Method | Endpoint |
|---------|--------|----------|
| Получить мои словари | GET | `/api/user/dictionaries` |
| Создать словарь | POST | `/api/user/dictionaries` |
| Обновить словарь | PUT | `/api/user/dictionaries` |
| Удалить словарь | DELETE | `/api/user/dictionaries?id={id}` |
| Получить маркетплейс | GET | `/api/marketplace/dictionaries` |
| Предпросмотр словаря | GET | `/api/marketplace/dictionaries/{id}` |
| Добавить в библиотеку | POST | `/api/marketplace/dictionaries/{id}/add` |
| Информация о генерациях | GET | `/api/user/generation-info` |
| Генерация словаря | POST | `/api/generate-dictionary` |

### Пример запроса генерации
```javascript
fetch('/api/generate-dictionary', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    topic: "Животные Африки",
    source_lang: "ru",
    target_lang: "en",
    difficulty: "medium",
    count: 20,
    category: "animals",
    preview: true  // не тратить генерацию
  })
})
```

## Контакты и поддержка

При возникновении проблем с интерфейсом:
1. Проверьте консоль браузера на ошибки
2. Убедитесь, что backend запущен
3. Проверьте сетевые запросы во вкладке Network

Для обратной связи используйте кнопку "Обратная связь" в главном меню.
